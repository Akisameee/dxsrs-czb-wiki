# 大侠式人生重制版资料工具

## Features

- 武学配装模拟器：选择武学后统计门派连锁、风格连锁，并支持装备词条和自创外功补充计数。
- 自创武学模拟：输入四维和武器类型，模拟初始结果，以及贪心锁定后的风格、攻击范围、特殊效果和威力分布。
- 自创武学初始搜索：按目标风格、攻击范围、特殊效果和效果等级搜索可能的初始四维，并按命中概率和威力结果排序。

## RE

### 存档组织形式

游戏的 `saves` 目录里混合了两类文件：

1. 人物主存档：体积较大，使用 BGDatabase binary 格式，保存角色、背包、武学、任务、NPC 等主要游戏数据。

2. 附属小存档：体积较小，使用 ES2 格式，保存存档槽索引、当前存档槽、经脉冲穴记录、难度、音量、TapTap 状态等配置或缓存数据。

ES2 小存档的文件名不是原始 key，而是由 `DBKey` 名称计算出来的数字字符串。规则是旧版 .NET/Mono 字符串 hash 取绝对值后加 `31489`。因此可以从已知 `DBKey` 表把数字文件名反查为业务含义，但不能从任意 hash 直接还原原字符串。

### 自创武学初始化

自创武学的初始状态由四维和武器类型共同决定。游戏按照如下方式计算：

1. 将四维和武器类型映射成random seed，并用这个seed初始化随机序列。

```text
seed = 意念 + 气劲 * 11 + 形态 * 111 + 神韵 * 1111 + 武器类型 * 11111 + 11111
```

2. 从同武器类型的非自创武学里随机抽取一个初始模板。

3. 从风格权重池里抽取初始风格。

4. 随机目标成长进度和初始成长进度，再由两者的差值计算初始改良空间。

```text
目标成长进度 = Random.Range(80, 100)
成长进度 = Random.Range(20, 40)
改良空间 = round((目标成长进度 - 成长进度) / 4)
```

5. 根据武器类型和成长进度，在威力配置里找到对应区间，得到初始品阶和真气消耗。

6. 根据当前品阶，从效果候选池中抽取初始特殊效果。1 到 3 品阶用低品阶效果池，4 到 5 品阶用高品阶效果池。

7. 计算威力。威力先在当前武器和品阶对应的最小/最大威力之间按成长进度线性插值，再乘以当前效果的倍率。

```text
品阶 = 当前威力区间的品阶
真气消耗 = 当前威力区间的消耗
区间进度 = (成长进度 - 区间下限) / (区间上限 - 区间下限)
基础威力 = 最小威力 + (最大威力 - 最小威力) * 区间进度
威力 = 基础威力 * 效果倍率
```

### 自创武学改良

改良过程不能被玩家完全控制，因为游戏每次改良都会使用Unity全局随机序列，和初始种子无关。游戏按照如下方式计算：

1. 推进成长进度，并消耗 1 次改良空间。

```text
成长进度 += 4 * Random.Range(1, 1.25)
改良空间 -= 1
```

2. 根据新的成长进度重新计算品阶和真气消耗。成长进度跨过新的威力区间时，品阶可能随之变化。

3. 对没有锁定的项目重新随机：风格来自风格权重池；攻击范围来自同武器、非自创、同候选品阶组的已有武学模板；特殊效果来自当前品阶组对应的效果候选池。

4. 按照初始化 2. 中的方式用最新的成长进度、品阶和特殊效果重新计算威力。

改良结束后，最终成长进度主要由初始成长进度、初始改良空间和每次改良的随机增量决定。目标成长进度只用于计算初始改良空间，后续不是硬上限。

由于 改良空间 = round((目标成长 - 成长进度) / 4)，理论最高最终成长进度出现在初始成长进度约 22、目标成长进度接近 100、改良空间仍为 20 的边界附近。

最终品阶、真气消耗和基础威力由最终成长进度所在的威力区间决定；特殊效果再用威力倍率修正最终威力，所以命中某些效果后威力可能下降。风格不参与基础威力计算。

这也是当前工具需要模拟的原因：最终成长进度可以估算，但目标词条的命中率还取决于每次改良的独立随机结果；范围和效果的候选池还会随品阶变化。为了估计目标组合能否成型，工具会对同一个初始输入重复跑多条改良路径。

在搜索和概率统计里，工具默认采用一个贪心锁定策略：目标风格、目标攻击范围、目标特殊效果中，哪个已经出现，就在后续改良中锁定哪个；还没出现的目标继续不锁，等待后续随机。然后用蒙特卡洛模拟统计目标风格、攻击范围、特殊效果等级、最终威力等结果的概率分布。
